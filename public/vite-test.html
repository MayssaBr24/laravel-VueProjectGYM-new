Diagnostic Vite + Laravel

Vérifiez votre configuration pour résoudre l'erreur 404

Votre configuration Vite

✓ Hôte et port

Votre serveur Vite est configuré sur localhost:5173

⚠ Configuration CORS

Vérifiez que votre application Laravel est bien servie sur http://localhost:8000 ou http://localhost:9000

✓ Point d'entrée

Votre point d'entrée est configuré sur resources/js/app.js

✓ Alias

L'alias @ est configuré vers /resources/js

Étapes de vérification

  • Lancez npm run dev pour démarrer Vite
  • Vérifiez que le port 5173 n'est pas utilisé par autre chose
  • Assurez-vous que votre application Laravel utilise bien le bon URL
  • Vérifiez la console navigateur pour les erreurs de chargement d'assets

Causes possibles d'erreur 404

  • Vite n'est pas en cours d'exécution
  • Le port est bloqué ou utilisé par une autre application
  • Problème de configuration CORS
  • Problème de chemin dans les assets

Configuration recommandée

// vite.config.js
import { defineConfig } from 'vite';
import laravel from 'laravel-vite-plugin';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
    server: {
        host: 'localhost',
        port: 5173,
        cors: {
            origin: ['http://localhost:8000'],
            credentials: true,
        },
    },
    plugins: [
        laravel({
            input: 'resources/js/app.js',
            refresh: true,
        }),
        vue({
            template: {
                transformAssetUrls: {
                    base: null,
                    includeAbsolute: false,
                },
            },
        }),
    ],
    resolve: {
        alias: {
            '@': '/resources/js',
        },
    },
});
